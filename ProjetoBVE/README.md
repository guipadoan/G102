# Projeto BVE – Buena Vista Energy

Este repositório reúne os documentos do estudo de simulação da operação de abastecimento de navios (bunkering) da Buena Vista Energy no Porto Mar Azul. O objetivo é avaliar alternativas para expandir a capacidade do sistema em 20%.
